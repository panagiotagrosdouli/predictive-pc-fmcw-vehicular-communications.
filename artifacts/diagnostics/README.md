# Diagnostic Artifacts

**Scope:** `HISTORICAL_DIAGNOSTIC`

This directory is the target home for exploratory, development and mechanism-discovery artifacts that are scientifically useful but are not final publication evidence.

Existing legacy diagnostic outputs are not moved here automatically because path changes could break provenance or workflows. Migration must preserve original paths/hashes or provide an explicit mapping manifest.

A diagnostic result may motivate a frozen experiment, but CI success or a favorable diagnostic outcome never promotes it to `paper1_final` or `paper2_final` evidence.
