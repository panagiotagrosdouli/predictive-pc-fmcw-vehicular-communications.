# Shared Artifacts

**Scope:** `SHARED`

This directory is reserved for frozen artifacts consumed by both publication scopes, such as the verified PC-FMCW/DPSK link mapping or other common assumptions whose provenance is independent of Paper-1 versus Paper-2 scientific claims.

Shared artifacts are reusable inputs, not duplicated scientific results. Each paper-specific manifest must explicitly declare which shared artifact version/hash it consumes.
