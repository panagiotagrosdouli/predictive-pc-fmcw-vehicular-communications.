# Paper 1 Final Artifacts

**Scope:** `PAPER1`

This directory is reserved for frozen publication evidence for the mechanism/operating-region paper.

No development, exploratory or historical result becomes canonical merely by being copied here. Every final artifact must be produced by a frozen Paper-1 protocol and include provenance sufficient to recover:

- code commit;
- configuration hash;
- input artifact hashes;
- scenario/episode/seed population;
- scheduler/predictor identities;
- statistical unit and analysis protocol;
- output hashes.

Until those gates pass, current prospective and diagnostic evidence remains under its existing diagnostic locations and is documented rather than silently reclassified.
