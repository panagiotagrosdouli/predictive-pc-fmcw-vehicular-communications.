# Shared Publication Material

**Scope label:** `SHARED`

This directory contains publication-facing material that is common to both Paper 1 and Paper 2 but is not itself a paper-specific scientific contribution.

Examples include the common PC-FMCW/DPSK system assumptions, causal geometry definitions, packet-outcome realization rule, notation, and reusable methodology text that both manuscripts may reference.

Reusable implementation remains under `src/predictive_pc_fmcw/`. Shared manuscript text must not duplicate or blur the distinct contribution claims of Paper 1 and Paper 2.
